# HMS HOME — لانشر Android TV + IPTV (Xtream Codes)

**الحالة بصراحة:** الكود اتكتب كامل، لكن **ما اتبناش ولا اتجرّب** (البيئة اللي اتكتب فيها مفيهاش Android SDK ولا إنترنت). هتلاقي أخطاء بناء بسيطة محتملة في أول Build — ابعتلي نص الخطأ وأصلحه.

## اللي اتغيّر في النسخة دي (v3)
- **الشبكة والدخول زي HMS Player بالظبط**: OkHttp 4.12 بنفس الإعدادات (نفس الـ User-Agent، مهلة اتصال 15 ثانية، تتبّع التحويلات http↔https) بدل HttpURLConnection القديم اللي كان بيفشل على بعض التيفي بوكسات.
- **شاشة حسابات متعددة** (IPTV accounts): إضافة / تعديل / حذف / اختيار الحساب الحالي، بتفهم لينك get.php الملصوق، وزر "Save without checking". الحساب القديم المحفوظ بيتنقل لوحده. لو الدخول فشل بيظهر سطر تقني بين [ ] يتصوّر ويتبعت.
- **إضافة حساب بطريقتين**: الكتابة بالريموت، أو **باركود**: التيفي يعرض QR، تصوّره بكاميرا الموبايل (لازم على نفس الواي فاي)، تكتب البيانات في صفحة بتفتح على الموبايل وتضغط إرسال، فالتيفي يتحقق ويحفظ. السيرفر المؤقت شغال طول ما نافذة الباركود مفتوحة بس، وجواه كود عشوائي، والبيانات مابتخرجش برا الشبكة المحلية.
- **مصدر "الجديد" في الهوم**: Settings ← *Home: new movies from* / *Home: new series from* تختار أي فولدر من فولدرات السيرفر (مثلاً new egypt movie)، أو تسيبه Automatic (أحدث إضافات). اسم الفولدر بيظهر كعنوان الصف.
- **جودة الصور**: كروت الهيرو بتتحمّل بجودة كاملة (ARGB_8888) ومفتاح الكاش فيه المقاس، وأفلام الهيرو بتجيب صورة عريضة (backdrop) من `get_vod_info` بدل البوستر الصغير.
- **المشغل زي HMS Player**: نفس إعدادات ExoPlayer (مهلات، بافر 20/60 ثانية)، البث المباشر `.m3u8`، وإعادة اتصال تلقائي (حد 2 محاولة لفيلم ما اشتغلش، و8 للباقي).
- **واجهة جديدة** على شكل التصميم: كروت هيرو (جديد المسلسلات/الأفلام + كمّل المشاهدة)، شريط التطبيقات، صف الاختصارات (Live / Movies / Series / Search / All apps / Accounts).
- **أيقونات فوق يمين**: Wi-Fi، **⚙ إعدادات الجهاز (إعدادات أندرويد)**، **⚟ إعدادات HMS HOME**. ولسه فيه "Device settings" جوه Settings.
- باقي الشاشات (Live/Movies/Series/Settings/Apps) لسه بالثيم الغامق القديم.

## المواصفات
- Package: `com.hms.home` | minSdk 21 (بيشتغل على أندرويد 7.0 وأحدث) | Java + Views عادية (بدون Compose)
- مكتبات: RecyclerView + OkHttp 4.12 + ExoPlayer 2.19.1 (core, hls, ui). مفيش Glide ولا Retrofit.
- مفيش sharedUserId ولا صلاحيات Droidlogic. الصلاحيات: INTERNET + ACCESS_NETWORK_STATE بس.

## البناء والنشر (زي HMS Player بالظبط)
1. ارفع المشروع على GitHub.
2. ضيف 4 أسرار في المستودع: Settings ← Secrets and variables ← Actions:
   `KEYSTORE_B64` و `KEYSTORE_PASSWORD` و `KEY_ALIAS` و `KEY_PASSWORD`
   **استخدم نفس القيم بتاعت HMS Player** (نفس المفتاح) — وماترفعش ملف `.jks` على GitHub.
3. بناء تجريبي: Actions ← Run workflow ← نزّل `HMS-Home-APK` من Artifacts.
4. نشر إصدار:
   ```
   git tag v1.0.0
   git push --tags
   ```
   الـ APK بيطلع في Releases باسم `HMS-Home-1.0.0.apk`.
- بناء محلي من غير مفتاح (Android Studio): الـ APK بيتوقّع بمفتاح debug وبيتثبّت عادي للتجربة.
- **كل التحديثات لازم تتوقّع بنفس المفتاح** وإلا أندرويد يرفض التثبيت.

## التحديث أونلاين من جوه التطبيق
- Settings ← **Check for updates**: بيدوّر على آخر Release على GitHub، وبيحمّله وبيفتح شاشة التثبيت.
- مصدر التحديثات مكتوب في `app/src/main/java/com/hms/home/data/Updater.java` (`GITHUB_REPO`) — **لازم يطابق اسم مستودعك على GitHub (Public)**.
- لنشر تحديث: غيّر الكود، وبعدين `git tag v1.0.1` ثم `git push --tags`. الرقم لازم يكون أكبر من الإصدار المتثبّت.
- أول مرة أندرويد ممكن يطلب تسمح بـ "Install unknown apps" للتطبيق.

## الخط والشاشة الكاملة
- Settings ← **Font size** (Normal / Large / Extra large). الافتراضي Large.
- التطبيق بيخفي شريط أندرويد (رجوع/هوم) ويشتغل فل سكرين.

## التثبيت على التيفي بوكس
- لو كان فيه نسخة قديمة من HMS HOME متثبّتة بتوقيع مختلف: **امسحها الأول** وبعدين ثبّت الجديدة.
- USB: حط الـ APK على فلاشة وافتحه بمدير ملفات (فعّل "Unknown sources").
- أو ADB: `adb connect IP:5555` ثم `adb install -r app-release.apk`

## تخليه الواجهة الرئيسية
- من جوه التطبيق: SETTINGS ← Set HMS HOME as default home، أو اضغط زر HOME في الريموت واختار **HMS HOME** ثم **Always**.
- لو اللانشر القديم متثبّت كـ Default: Settings ← Apps ← اللانشر القديم ← **Clear defaults**، وبعدها اضغط HOME.
- اللانشر القديم يفضل موجود كاحتياطي، ومفيش تعديل على الروم.

## الريموت
- OK يفتح/يشغّل | BACK خطوة لورا (الهوم مبيتقفلش) | MENU أو **OK مطوّل** = خيارات / مفضلة
- في المشغل (لايف): فوق/تحت = القناة اللي بعدها/اللي قبلها، MENU = قايمة القنوات
- في المشغل (أفلام): يمين/شمال = ±10 ثانية، OK = الكنترولز (Audio / Subtitles / Aspect)

## ملاحظات أداء
- أول فتح بعد تسجيل الدخول بينزّل فهرس الأفلام والمسلسلات في ملف كاش (بيتقري Stream من غير ما يتحمّل في الرام) ويتجدد كل 6 ساعات.
- صور: كاش رام 6MB + كاش ديسك حوالي 40MB، والمشغل Instance واحد بيتقفل في onStop.
- كلمة السر متخزنة مشفّرة بـ Android Keystore (لو الجهاز Keystore بتاعه بايظ بتتخزن بتمويه بسيط بدل التشفير).

## اللي لسه ناقص / ممكن يحتاج تعديل
- التطبيق كله ما اتجرّبش على جهاز. أول حاجة تتجرّب: تسجيل الدخول، تشغيل قناة، فيلم، حلقة، وفتح تطبيق من المفضلة.
- الـ EPG بيعتمد على إن السيرفر يدعم `get_short_epg`.
- Subtitles: بتظهر لو الستريم فيه ترجمة مدمجة (مفيش تحميل ترجمة خارجية).
- الخط: خط النظام (Roboto/Noto) — مفيش خطوط مخصصة.
- الأيقونة والبانر Vector بسيطين؛ ممكن تستبدلهم بـ PNG.
